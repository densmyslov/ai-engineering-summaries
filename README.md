# Cloudflare Connect 2026: talk summaries

An interactive, clickable tree of summaries for the 13 talks in the Cloudflare Connect 2026 playlist, in English and Russian, with a dark/light theme.

- Live page: https://densmyslov.github.io/cloudflare-connect-2026-summaries/
- Plain markdown: [summaries.md](summaries.md)

The summaries were made from the talks' YouTube auto-captions, so a few names may be imprecise. Those spots are flagged in the text.
